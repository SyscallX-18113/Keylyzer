# Changelog

All notable changes to Keylyzer are documented in this file.

## [1.0.0] - Initial Release

### Added
- Support for 60+ API service integrations.
- Centralized API credential validation through a command-line interface.
- HTTP request handling using libcurl.
- JWT analysis functionality for inspecting token headers and payloads locally.
- C-based implementation designed for lightweight command-line use.
